# 静数独

无广告的离线数独网页版，适合手机和电脑。

游戏网址：https://WinXPQAQ.github.io/jingshudu/

## 玩法

网页版 0.3.0：五档难度，每档 10,000 道，共 50,000 道已验证题目。选格填数、候选数笔记、撤销、擦除、重复冲突提示、辅助增强与本地自动存档。新游戏选难度后直接开局。

iPhone 用 Safari 打开网址，分享 → 添加到主屏幕。首次联网等待“已可离线使用”后，可以离线游玩。存档只在当前浏览器中保存，建议通过“存档与备份”定期导出；网页版不与安卓 App 自动同步。

本版从未玩过的题中随机选题，暂不实时生成。最近 300 步可撤销。

已开过的题会记录在当前浏览器；同档题全部玩过后会提示，不会自动循环重复。导出包含已玩记录，导入时与本机记录合并。旧版未记录已玩历史，只能补记当前存档；清除浏览器数据会删除记录。

## 检查点

仅“超级难”和“无敌难”可用。点击“建立检查点”后需要再次确认，保存当前填数和全部备注。每局只能建立一次，不能覆盖或删除；之后可无限次“回到检查点”。返回操作可以撤销，检查点本身不受撤销影响。

检查点随自动存档和 JSON 备份保留；旧存档没有检查点时仍可正常继续，新游戏重新获得一次建立机会。已完成的游戏不能新建检查点，但已有检查点仍可返回。

## 难度筛选

基础解法限定单值、唯一候选、区块排除、显性及隐性数对。基础解法卡住后，检查每一个二候选格的正确假设：一次假设就能用基础技巧通关的题，最高归为“非常难”。“超级难”和“无敌难”必须排除所有零次／一次正确二候选假设的通关路径，另外还需通过原有高级逻辑技巧评级。

这里的“两次以上”是成功路径所需二候选假设数的下界，不是把猜错次数或 DFS 遍历节点算作难度；不能阻止玩家连续两次幸运猜中。筛选与独立复查方法见 tools/README.md。

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root)。无需编译、域名或服务器。项目根目录就是发布目录。

## Cloudflare Pages

在 Cloudflare 中创建 Pages 项目，连接本仓库：Production branch 选 main，Framework preset 选 None，Build command 留空，Build output directory 填 /（仓库根目录）。

也可以使用 Direct Upload 上传网页静态文件包。请选择 Pages，不是需要 Worker 入口的项目。平台免费额度与大陆网络可达性以实际使用情况为准。

## 本地验证

npm ci && npm test。测试依赖不会被游戏加载，线上无需安装依赖。

自动化检查覆盖游戏规则、防重复、历史备份合并、DOM 交互及离线缓存；独立 JavaScript 校验器逐题检查 50,000 道题的唯一解，并逐分支复查两档高难题不存在一次二候选通关捷径。验收结果见 VERIFICATION.md。尚未做 iPhone 真机测试。

更新网页时需递增 sw.js 的缓存版本，已打开的旧页面关闭后激活新版本。
